## ⚡ Quick Start

1. Download an add-on package compatible with your Microsoft Flight Simulator version.
2. Extract the archive and locate the add-on's package folder.
3. Copy the package folder into your simulator's `Community` folder.

Restart the simulator and check Marketplace → My Library → Community to confirm that the add-on appears.

## ❓ FAQ

**Do I need to run mods as Administrator?**

No — standard user access is normally sufficient to copy add-on packages into your Community folder.

**Can antivirus software flag MSFS mods?**

Some security tools may flag unfamiliar installers or utility files. Download add-ons from trusted creators and review files before installation.

**Do MSFS Mods work on Windows 11?**

Yes, Microsoft Flight Simulator 2024 supports Windows PC installations. Individual add-ons have their own system and simulator-version requirements.

**Where do I install MSFS Mods?**

On PC, third-party packages are generally installed in the simulator's Community folder. You can locate it through Marketplace → My Library → Settings.

**Are MSFS 2020 mods compatible with MSFS 2024?**

Some add-ons carry over, but compatibility is not universal. Check the creator's MSFS 2024 compatibility information before installing.
